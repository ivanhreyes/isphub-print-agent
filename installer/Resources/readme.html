Qué necesitas

  • Una Mac con chip Apple Silicon (M1, M2, M3 o M4).
  • macOS 13 o más nuevo.
  • La impresora EC-PM-80330 conectada a la misma red local que la Mac.

La impresora es de red (puerto 9100, ESC/POS), así que no necesita drivers ni software adicional. El agente es un único programa que no depende de Node, Python ni nada más.

El agente solo escucha en 127.0.0.1:8787, dentro de esta Mac. No abre puertos hacia la red del negocio y se conecta únicamente a la impresora.
